# Sorted! The Trash Game

Website, support page and privacy policy for the Sorted! iOS game.

Live at https://mattsparks77.github.io/sorted/

- `index.html` — landing page with a playable swipe demo (`app.js`). Demo items, sprites and answers come from the game's own item data.
- `support.html` — FAQ and contact.
- `privacy.html` — privacy policy.
